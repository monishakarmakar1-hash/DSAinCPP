# DSA in C++

A structured collection of Data Structures and Algorithms practice programs written in C++.

## Contents

All lessons and examples are kept in serial order so the repository is easy to follow from the beginning.

### 01. Pattern Problems

1. [`patterns.cpp`](./patterns.cpp)
2. [`pattern3.cpp`](./pattern3.cpp)
3. [`pattern4.cpp`](./pattern4.cpp)
4. [`pattern5.cpp`](./pattern5.cpp)

> Compiled executable files are intentionally excluded from version control. Compile any example locally with a C++ compiler.

## How to run

```bash
g++ pattern4.cpp -o pattern4
./pattern4
```

On Windows PowerShell:

```powershell
g++ pattern4.cpp -o pattern4.exe
.\pattern4.exe
```
